BREATHE.COFFEE SINGLE-PAGE WEBSITE
==================================

FILES
- index.html
- css/style.css
- css/responsive.css
- js/script.js

HOW TO RUN
1. Open this folder in VS Code.
2. Open index.html with Live Server.
3. The website works on desktop, tablet and mobile.

CONTACT DETAILS
Phone, WhatsApp and Google Maps are updated with the supplied official details.
The email is still a placeholder and can be changed in the CAFE object at the
top of js/script.js.

Instagram and Facebook currently use # placeholder links as requested.

IMAGES
The supplied original Breathe.Coffee logo and venue images are stored locally in
assets/images and used in the hero, about, gallery, header and footer. Some menu
food images remain relevant Unsplash demo images until official menu photos are
supplied.

TIMINGS
Monday to Sunday: 8:00 AM to 12:00 PM, as supplied.

FEATURES
- Sticky responsive header
- Working mobile slide menu and close button
- Smooth one-page navigation
- Animated sections and hover effects
- Responsive menu cards
- FAQ accordion
- Gallery lightbox
- Testimonial slider
- WhatsApp reservation form
- Floating Call and WhatsApp buttons
- SEO meta tags and LocalBusiness schema
- Accessible labels and reduced-motion support
